### Hi, I'm sas0208

(Claude Code, Codex, local models) write and verify the code, and I review, correct and ship.

**Showcases**

  built by a pipeline of AI agents: editor automation, C++ tests and visual verification.
- **[Live chat for websites](https://github.com/sas0208/chat-clienti-showcase)** — customer-support chat on
  Cloudflare Workers + Durable Objects, WebSocket and push notifications, in production.
- **[AETHER](https://github.com/sas0208/aether-showcase)** — my personal, distributed AI operating system: one Core
  on a laptop, heavy jobs on a workstation, agents coordinated from the phone.
